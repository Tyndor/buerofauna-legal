# Bürofauna — Rechtliches

Öffentlich erreichbare Rechtstexte zur Android-App **Bürofauna**:
Datenschutzerklärung und Impressum. Ausgeliefert über GitHub Pages, damit
Google Play eine dauerhaft erreichbare URL ohne Anmeldung prüfen kann.

Der Quelltext der App liegt in einem eigenen, privaten Repository. Hier
stehen ausschließlich die beiden Rechtstexte — Änderungen daran sind
sofort öffentlich wirksam.
